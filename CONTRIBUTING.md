# Contribuir

Abre una issue con una reproducción concreta antes de cambios grandes. Para fallos de consola indica firmware, versiones de kstuff y ShadowMount, formato de carga y código de error. No adjuntes datos personales ni material propietario.

Separa las reglas del juego en `src/game.hpp` de la entrada y el renderer. Añade pruebas para reglas nuevas y revisa las previews. Usa C++20 y el formato del repositorio. Conserva las licencias de terceros.

Una pull request debe explicar el comportamiento que cambia, cómo se ha probado y si requiere validación en hardware. No conviertas un resultado de escritorio en una afirmación de compatibilidad con PS5.
